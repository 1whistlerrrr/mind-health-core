## 🎯 脚本概述
这个脚本使用 `Qwen/Qwen2.5-0.5B-Instruct` 模型（很小的中文模型），配合 LoRA（Low-Rank Adaptation，低秩适应）技术进行参数高效微调。

**流程步骤：**
1. 用 ModelScope 下载模型
2. 测试原模型的问答效果
3. 用内置演示数据微调
4. 测试微调后的模型
5. 对比两者的输出效果

### 第 3 部分：生成函数 (Line 50-63)

```python
def generate_with_model(model, prompt):
    messages = [{"role": "user", "content": prompt}]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer([text], return_tensors="pt").to(model.device)
    with torch.no_grad():
        output_ids = model.generate(
            **inputs,
            max_new_tokens=128,
            temperature=0.7,
            top_p=0.95,
            do_sample=True,
        )
    return tokenizer.decode(output_ids[0][len(inputs["input_ids"][0]):], skip_special_tokens=True)
```

**这部分作用：**
- 一个通用的生成函数，根据输入问题得到回答
- `tokenizer.apply_chat_template`：把问题格式化成对话格式
- `torch.no_grad()`：不计算梯度，只做推理
- `max_new_tokens=128`：最多生成 128 个 token
- `temperature=0.7`：控制随机性（越大越随机）

### 第 5 部分：准备微调 (Line 78-109)

```python
time.sleep(1)
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,  # 4bit 量化！
    bnb_4bit_use_double_quant=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16
)

model_for_train = AutoModelForCausalLM.from_pretrained(
    MODEL_NAME,
    quantization_config=bnb_config,  # 加载 4bit 模型
    device_map="auto",
    trust_remote_code=True,
    low_cpu_mem_usage=True,
    use_safetensors=True,
)

lora_config = LoraConfig(
    r=8,  # LoRA 秩（越小参数越少）
    lora_alpha=16,  # LoRA alpha
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],  # 要修改的层
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
)
model_for_train = get_peft_model(model_for_train, lora_config)
model_for_train.print_trainable_parameters()
```

**这部分作用：**
- `BitsAndBytesConfig`：设置 4bit 量化，极大节省显存！
  - 原模型 0.5B → 用 4bit 量化后，只需要 ~300MB 显存！
- `LoraConfig`：设置 LoRA 参数
  - `r=8`：秩（rank），表示矩阵分解的维度
  - `target_modules`：哪些层用 LoRA 调整
- `get_peft_model`：把模型变成 LoRA 版本
- `print_trainable_parameters()`：打印可训练参数比例！通常只有 ~0.1%

### 第 7 部分：数据格式化 (Line 126-158)

```python
def format_example(example):
    instruction = example["instruction"]
    input_text = example["input"] if example["input"] is not None else ""
    output = example["output"]
    
    if input_text:
        prompt = f"""&lt;|im_start|&gt;user
{instruction}
{input_text}&lt;|im_end|&gt;
&lt;|im_start|&gt;assistant
{output}&lt;|im_end|&gt;"""
    else:
        prompt = f"""&lt;|im_start|&gt;user
{instruction}&lt;|im_end|&gt;
&lt;|im_start|&gt;assistant
{output}&lt;|im_end|&gt;"""
    
    tokenized = tokenizer(
        prompt, truncation=True, max_length=MAX_SEQ_LEN,
        padding="max_length", return_tensors="pt"
    )
    labels = tokenized["input_ids"].clone()
    labels[labels == tokenizer.pad_token_id] = -100  # 把填充标记设为 -100，不计算损失
    return {
        "input_ids": tokenized["input_ids"].squeeze(),
        "attention_mask": tokenized["attention_mask"].squeeze(),
        "labels": labels.squeeze(),
    }

from datasets import Dataset as HFDataset
dataset = HFDataset.from_list(demo_data)
dataset = dataset.map(format_example, remove_columns=dataset.column_names)
```

**这部分作用：**
- `format_example`：把问答对格式化成模型能看懂的格式
  - 用 `&lt;|im_start|&gt;` 和 `&lt;|im_end|&gt;` 分隔对话角色
- `labels[labels == tokenizer.pad_token_id] = -100`
  - **非常重要！**这表示：填充的部分我们不算损失，只算 `output`（回答）部分的损失
  - `loss_mask` 的本质，只对我们想要训练的部分（assistant 的回答）计算梯度

### 第 8 部分：设置训练参数 (Line 160-176)

```python
training_args = TrainingArguments(
    output_dir=OUTPUT_DIR,  # 保存结果的目录
    per_device_train_batch_size=TRAIN_BATCH_SIZE,  # 每批多少样本
    gradient_accumulation_steps=GRADIENT_ACCUMULATION_STEPS,  # 梯度累积
    learning_rate=LEARNING_RATE,  # 学习率
    max_steps=MAX_STEPS,  # 最多训练多少步
    logging_steps=20,  # 每20步打印一次
    save_steps=100,  # 每100步保存一次
    warmup_steps=10,  # 预热步数
    optim="paged_adamw_32bit",  # 优化器
    gradient_checkpointing=True,  # 梯度检查点，节省显存
    report_to="none",
    bf16=torch.cuda.is_bf16_supported(),
    save_total_limit=2,
    remove_unused_columns=False,
    ddp_timeout=900,
)
```

**这部分作用：**
- 设置训练时的各种超参数
- `gradient_accumulation_steps`：梯度累积，用于模拟更大的 batch size
- `gradient_checkpointing=True`：用时间换显存，显存占用更低但训练稍慢

## 📖 关键概念说明

---

### 1. 什么是 LoRA？
LoRA（Low-Rank Adaptation）是一种参数高效微调方法。它不直接修改原模型的所有参数，而是在一些关键层添加额外的小矩阵（低秩矩阵），只训练这些小矩阵！

**优点：**
- 参数极少！通常只占 0.1%~5%
- 训练快！显存占用低！
- 模型加载快！

---

### 2. 什么是 4bit 量化？
量化是把浮点数用更少的位表示，降低计算和存储成本。

- 普通模型用 `float32`（32位）
- 半精度用 `float16`（16位）
- 我们用的是 `int4`（4位），通过量化技术
- 效果：显存占用直接减 4 倍！

---

### 3. 什么是 Training Arguments？
`TrainingArguments` 是 transformers 库提供的训练参数配置，控制训练流程的方方面面。

---

### 4. 为什么要用 loss_mask？
微调对话模型时，我们只希望模型学习我们给的答案部分（assistant 说的话），而不是用户的问题！
- 把用户问题部分的 labels 设为 `-100`，损失函数就会自动忽略，不算梯度！
