
# 📚 公开中文微调数据集说明

根据搜索结果，找到了多个高质量的中文微调数据集！

---

## 1. Alpaca-Chinese (alpaca-zh) ⭐ 推荐入门
- **规模：** 5万条
- **来源：** 用 ChatGPT API 翻译 Alpaca
- **格式：** 标准的 `instruction-input-output` 格式
- **优点：** 数据质量高，格式统一，加载简单
- **使用：** HuggingFace上的 `shibing624/alpaca-zh`
- **备注：** 我们脚本默认选择这个！

---

## 2. BELLE ⭐ 海量数据
- **规模：** 300万+条！
- **来源：** 贝壳团队 Self-Instruct 生成
- **项目地址：** https://github.com/LianjiaTech/BELLE
- **优点：** 数量巨大，覆盖广，中文质量好
- **备注：** 适合想做大批量训练的场景

---

## 3. Firefly
- **开源：** 是
- **特点：** 也是高质量的中文指令数据集
- **格式：** 类似 Alpaca

## 📝 修改数据量的方式

在代码里找到这一行：
```python
dataset = dataset["train"].select(range(min(5000, len(dataset["train"]))))
```
把 `5000` 改成你想要的数量（比如 1000 或 10000）
