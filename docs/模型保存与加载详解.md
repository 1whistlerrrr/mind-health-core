
# 📦 MiniMind 模型保存与加载详解

## 🤔 `.pth` 文件里存了什么？

**PyTorch 模型文件**，通常是一个字典，包含：

| 字段 | 说明 |
|------|------|
| `model_state_dict` | 模型的所有参数（权重、偏置等） |
| `optimizer_state_dict` | 优化器的状态（可选，用于继续训练） |
| `epoch` | 训练到第几轮了（可选） |
| `loss` | 最后的训练 loss（可选） |
| `config` | 模型的配置（可选，推荐保存） |

```python
checkpoint = {

        'seq_len': config.seq_len,
        # 其他你需要的配置...
    }
}
torch.save(checkpoint, 'minimind_model.pth')
```

## 🚀 如何使用保存的模型？

### 使用场景1：推理（生成文本）

```python
import torch
from model import MiniMind
from config import Config

def load_for_inference():
    # 1. 加载 checkpoint
    checkpoint = torch.load('minimind_model.pth', map_location='cpu')

    # 2. 创建模型
    config = Config()  # 或者用 checkpoint 里的 config
    model = MiniMind(config)

    # 3. 加载参数
    model.load_state_dict(checkpoint['model_state_dict'])
    model.eval()  # 切换到评估模式

    return model
```

### 使用场景2：继续训练（微调）

```python
def load_for_finetune():
    # 1. 加载 checkpoint
    checkpoint = torch.load('minimind_model.pth')

    # 2. 创建模型和优化器
    model = MiniMind(config)
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4)

    # 3. 加载参数
    model.load_state_dict(checkpoint['model_state_dict'])
    optimizer.load_state_dict(checkpoint['optimizer_state_dict'])

    # 4. 获取训练进度
    start_epoch = checkpoint['epoch'] + 1

    return model, optimizer, start_epoch
```

## ⚠️ 重要提示：别忘了 Tokenizer！

**模型只是「大脑」，你还需要「翻译器」—— Tokenizer！**

### 你应该同时保存 Tokenizer

```python
# 保存
import pickle
with open('tokenizer.pkl', 'wb') as f:
    pickle.dump(tokenizer, f)

# 加载
with open('tokenizer.pkl', 'rb') as f:
    tokenizer = pickle.load(f)
```

## 📝 完整的工作流程示例

```python
# =================== 保存阶段 ===================
# 1. 训练模型...
# 2. 保存模型和 tokenizer
checkpoint = {
    'model_state_dict': model.state_dict(),
    'config': config.__dict__,
    'tokenizer_vocab': tokenizer.vocab,
    # ...其他信息
}
torch.save(checkpoint, 'minimind_model.pth')

# =================== 加载阶段 ===================
# 1. 加载
checkpoint = torch.load('minimind_model.pth')
config = Config(checkpoint['config'])
model = MiniMind(config)
model.load_state_dict(checkpoint['model_state_dict'])

# 2. 推理
model.eval()
with torch.no_grad():
    output = model(input_ids)

# 3. 或者继续训练
model.train()
# ...继续你的训练...
```

## 🎓 总结

| 场景 | 你需要做什么 |
|------|-------------|
| 训练后保存 | `torch.save()` 保存 model 和 optimizer 和 config |
| 推理生成 | 加载 model，切换到 `model.eval()`，`torch.no_grad()` |
| 继续训练 | 加载 model + optimizer，恢复训练进度 |
| 迁移学习 | 加载预训练 model，修改最后几层，训练新数据 |
