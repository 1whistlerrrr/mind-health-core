
# 🤖 MiniMind - 你的第一个从零实现的大模型！

完全从零实现的大语言模型，用可理解的代码，包含所有核心组件。专门为学习和面试准备！

---

## ✨ 项目特色

- **📚 完整实现** - Tokenizer、Transformer、Attention、RoPE 全有
- **💡 教育性强** - 代码简单注释详细，适合学习
- **🚀 即插即用** - 有Demo模式，几分钟就能跑
- **📊 完整工具链** - 训练、保存、加载、推理、SFT 都有
- **🎯 面试友好** - 作为你的项目经验很棒！

## 🚀 快速开始

### 1. 安装依赖



然后选择 `2 - Demo`，5分钟就能训练完！

### 3. 试试推理

```bash
python train.py
# 选择 "5 - 推理模式"
```

输入你的提示，看模型生成！

## 🛠️ 核心组件详解

### 1. Tokenizer - 分词器
- 字符级 + 二元组
- 特殊符号处理
- 保存和加载

### 2. RMSNorm - 归一化
- 简化的LayerNorm
- 计算更高效
- LLaMA同款

### 3. RoPE - 旋转位置编码
- 旋转方式融入位置信息
- 天然支持外推
- LLaMA同款

### 4. 多头注意力
- 因果Mask（不能看未来）
- Q/K/V计算
- 多头拼接

### 5. FeedForward
- SwiGLU激活函数
- 门控线性层
- LLaMA同款

## 💾 模型保存和加载

### 保存
```python
# 方式一：完整保存（推荐）
model.save_pretrained("my_model")

# 方式二：仅保存权重
model.save("model.pt")
```

### 加载
```python
# 完整加载（推荐）
model = MiniMind.from_pretrained("my_model")

# 推理管道
from model import InferencePipeline
pipe = InferencePipeline("my_model")
output = pipe.generate("数学是什么？")
```
